# Как залить этот сайт на GitHub — пошагово, без командной строки

Внутри архива — **готовый сайт** LigmarBD со всеми правками. Ничего собирать и настраивать не нужно:
это просто папка с файлами, которую надо положить на GitHub и включить GitHub Pages.

**Что уже исправлено в этой версии:**
- при смене дополнительного свойства процент больше не сбрасывается — остаётся тот, что стоял;
- у каждого свойства есть кнопка **«Древка»** = 150 % (единственный способ получить выше 100 %);
- значения выше 100 % поставить нельзя: ввод обрезается, пресеты с 150 % убраны;
- пресеты (плохой / средний / хороший / 100 %) меняют только проценты, а не выбранные свойства;
- **иконки экипировки загружаются** — они лежат прямо в папке `assets/`, сайт больше не ходит за ними на ligmar.io;
- если какая-то картинка всё же не загрузится, вместо «сломанной» показывается аккуратная заглушка.

**Что осталось без картинок (их нет ни в репозитории, ни в таблице гильдии):** иконки умений, портреты мобов,
иллюстрации в гайте заточки. На их месте будет серая заглушка с «?» — это нормально и не ломает расчёты.
В таблице «Арсенал ASH» есть только иконки экипировки (тот же арт, что уже лежит в `assets/`), поэтому
оставшиеся битые картинки она не закрывает.

Выберите **один** из двух способов ниже. Способ 1 проще и надёжнее.

---

## Способ 1. GitHub Desktop (рекомендую) — программа, всё мышкой

Понадобится один раз установить программу GitHub Desktop. Команды вводить не придётся.

1. **Распакуйте архив.** После распаковки должна получиться папка `ligmar-site`, а в ней — файл
   `index.html` и папки `assets`, `data`, `guides`. (Если распаковалось в папку с папкой внутри —
   зайдите внутрь, до уровня, где виден `index.html`.)
2. **Установите GitHub Desktop:** откройте <https://desktop.github.com/> → скачайте → установите,
   нажимая «Далее». Запустите программу.
3. **Войдите в аккаунт:** при первом запуске программа предложит sign in → откроется браузер →
   войдите в свой GitHub и разрешите доступ.
4. **Привяжите папку:** в программе меню **File → Add Local Repository…** (или `Ctrl+O`) →
   выберите распакованную папку `ligmar-site`. Программа напишет, что здесь нет репозитория, —
   нажмите **create a repository** (создать репозиторий).
5. В окне создания оставьте имя `ligmar-site` (или своё) и путь как есть → **Create Repository**.
   Галочку «Initialize with README» ставить **не нужно**.
6. Слева появится список из ~130 изменённых файлов. Внизу в поле **Summary** напишите что угодно,
   например `Правки свойств и иконки` → нажмите синюю кнопку **Commit to main**.
7. Вверху появится кнопка **Publish repository** → нажмите её. В окне убедитесь, что имя совпадает
   с желаемым, галочку «Keep this code private» ставьте по желанию → **Publish Repository**.
   Готово: репозиторий создан на GitHub и все файлы уехали.

Переходите к разделу **«Включить GitHub Pages»**.

## Способ 2. Через браузер, без установки (в уже созданный пустой репозиторий)

Подходит, если вы уже создали пустой репозиторий на github.com. GitHub за одну загрузку принимает
не больше 100 файлов, а у нас 130, поэтому грузим **тремя порциями**.

1. **Распакуйте архив** до уровня, где виден `index.html`.
2. Откройте ваш репозиторий на github.com. Если он пустой, увидите кнопку **uploading an existing file** —
   нажмите её (или кнопку **Add file → Upload files**).
3. **Порция 1:** перетащите мышкой в окно загрузки папку `assets` **целиком** (70 файлов).
   Дождитесь, пока все полоски догрузятся, и нажмите зелёную **Commit changes**.
4. **Порция 2:** снова **Add file → Upload files**, перетащите папку `data` (26 файлов) → **Commit changes**.
5. **Порция 3:** снова **Add file → Upload files**, перетащите папку `guides` (6 файлов) **и все файлы
   из корня** (`index.html`, `app.js`, `styles.css` и остальные ~22) → **Commit changes**.
   Корневые файлы можно выделить все сразу: клик по первому, затем `Shift` + клик по последнему.
6. Проверьте: на главной странице репозитория теперь должны лежать `index.html`, папки `assets`,
   `data`, `guides` и россыпь `.js`/`.css` файлов.

Переходите к разделу **«Включить GitHub Pages»**.

## Включить GitHub Pages (обязательно, иначе сайта не будет)

1. В вашем репозитории откройте вкладку **Settings** (шестерёнка, справа сверху в репозитории).
2. В левом меню выберите **Pages**.
3. В блоке **Build and deployment → Source** выберите **Deploy from a branch**.
4. Ниже в **Branch** выберите ветку `main` (или `master`) и папку `/ (root)` → нажмите **Save**.
5. Подождите 1–3 минуты и обновите страницу Settings → Pages: сверху появится зелёная плашка
   с адресом вида `https://ВАШ-ЛОГИН.github.io/имя-репозитория/`. Это и есть ваш сайт.

## Проверка после загрузки

Откройте адрес сайта и убедитесь:
- раздел **Мои персонажи** открывается, кукла и слоты на месте;
- клик по слоту → окно предмета → в блоке «Дополнительные свойства» у каждого ряда есть селект
  процента и кнопка **«Древка»**;
- смените свойство в списке — процент остаётся прежним;
- нажмите «Древка» — станет 150 %, ряд подсветится оранжевым;
- иконки предметов видны (не серые квадраты и не «сломанные» картинки).

## Важное про сохранения персонажей

Сохранения живут в браузере и привязаны к **адресу** сайта. Если раньше вы вели персонажей на
`minibotan.github.io/LigmarBD`, а новый сайт будет на другом адресе, перенесите их так:
на старом сайте **Мои персонажи → ↓ Скачать билд**, затем на новом **↑ Загрузить** и выберите файл.

## Если что-то пошло не так

- Сайт открывается, но «белый экран» или «404» — почти наверняка Pages включён не на ту папку:
  в Settings → Pages ветка должна быть `main`/`master`, папка `/ (root)`.
- Загрузка файлов в браузере оборвалась на большом JSON — повторите загрузку только этого файла.
- Иконки серые — нажмите `Ctrl+F5` (жёсткая перезагрузка), чтобы сбросить кэш браузера.
- Что-то не получается — напишите мне, на каком именно шаге застряли и что видите на экране.
